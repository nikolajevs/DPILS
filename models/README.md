# Модели

## RobotExpressive.glb — модель игроков онлайн-шутера

Модель Tomás Laulhé ([Quaternius](https://quaternius.com)), лицензия **CC0 1.0** (общественное достояние), анимации: Idle, Walking, Running, Jump, Death и другие. Файл — из примеров [three.js](https://github.com/mrdoob/three.js/tree/master/examples/models/gltf/RobotExpressive) в обработке Don McCurdy (добавлены морфы мимики, конвертация FBX2glTF, убраны дубли материалов). Используется в [src/game/avatar.js](../src/game/avatar.js): оранжевый материал `Main` перекрашивается в цвет команды или игрока.
