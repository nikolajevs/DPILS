# Автономный цикл улучшений

Конвейер «улучшать то, что есть» без участия владельца: внешний драйвер запускает итерации агента одну за другой, каждая итерация берёт задачу из [бэклога](improvement-backlog.md) и доводит её до смерженного PR и сайта https://nikolajevs.github.io/DPILS/.

Одна итерация: свежий worktree от `origin/main` → задача из бэклога → реализация → `npm run check` / `npm test` / `npm run build` + визуальная проверка → обновление бэклога → PR → авто-мерж после зелёного CI → уборка worktree. Когда очередь пустеет (или после ~8 выполненных задач), итерация проводит **аудит**: кадры города днём и ночью, ошибки консоли, замеры производительности — и наполняет очередь новыми задачами. Поэтому цикл не заканчивается.

## Что нужно

- **Claude Code CLI** (`claude`), залогиненный в подписку Claude или с `ANTHROPIC_API_KEY`. Установка: `npm i -g @anthropic-ai/claude-code`, затем один раз запустить `claude` и войти. Это единственный шаг, требующий человека.
- `gh` с доступом к репозиторию (уже настроен), Node.js, Playwright Chromium для визуальных проверок.

## Запуск

```powershell
npm run loop                       # бесконечно, пока не остановить
npm run loop -- -MaxIterations 5   # 5 итераций и остановка
npm run loop -- -PauseSec 120 -Model sonnet
```

Драйвер — [tools/improve-loop.ps1](../tools/improve-loop.ps1), промпт итерации — [tools/improve-prompt.md](../tools/improve-prompt.md). Параметры драйвера: `-MaxIterations` (0 = бесконечно), `-PauseSec` (пауза между итерациями, по умолчанию 60), `-IterationTimeoutMin` (убить зависшую итерацию, 45), `-Model`, `-Agent` (команда headless-агента), `-Repo`.

Драйвер не зависит от ветки общего каталога: промпт итерации он каждый раз берёт из `origin/main`. Если общий каталог стоит на чужой ветке и `npm run loop` там недоступен, запускай локальный лаунчер `.claude\loop.cmd` (он сам извлекает свежий драйвер из `origin/main`; на этой машине уже создан) или `powershell -File tools\improve-loop.ps1` из любого worktree с `main`.

## Остановка и наблюдение

- Мягкая остановка: создать файл `LOOP-STOP` в корне репозитория (`New-Item LOOP-STOP -ItemType File`). Текущая итерация доработает, новая не начнётся. Удалить файл — чтобы снова разрешить запуск.
- Логи — `loop-logs/` (не в git): `iter-<n>-<время>.log` — полный вывод агента, `loop.log` — сводка по итерациям.
- Результат — раздел «Сделано» в [бэклоге](improvement-backlog.md) и история PR на GitHub.

## Защита от деградации и разгона

- Каждый PR небольшой и проходит CI (check + боевые тесты + build); авто-мерж только после зелёного CI. Неудачную итерацию можно откатить обычным revert-PR.
- Драйвер сам останавливается: 2 подряд ошибки агента; 3 подряд итерации без мержей в `main`; файл `LOOP-STOP`; лимит `-MaxIterations`.
- Одновременно работает только один цикл (lock-файл `loop-logs/loop.lock` с PID).
- Итерации уважают таблицу «Кто чем занят» и не трогают файлы параллельных агентов. Ветки `chatbox/loop-*` зарезервированы за циклом.
- Зависшую итерацию драйвер убивает по таймауту и подчищает оставленные worktree `chatbox/loop-*` (чужие worktree не трогает).

## Стоимость и пределы

Каждая итерация — полноценная сессия агента (токены подписки Claude или API). Разумный темп: `-MaxIterations 5–10` в день, пауза `-PauseSec` между итерациями. Машина должна быть включена и не спать. Цикл не заменяет глаза владельца: иногда смотрите сайт и журнал «Сделано», свои пожелания вписывайте в начало очереди бэклога.

## Автозапуск после перезагрузки (по желанию)

```powershell
schtasks /Create /TN "DPILS improve loop" /SC ONLOGON /TR "powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\Users\igors\Desktop\DPILS\tools\improve-loop.ps1 -MaxIterations 10"
```

Задача выполнится при входе пользователя (с его логином Claude) и ограничит себя 10 итерациями. Удалить: `schtasks /Delete /TN "DPILS improve loop" /F`.
