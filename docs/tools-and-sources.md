## Проверка в браузере без экрана: `tools/shots.js`

Рендерит заданные виды города в JPEG в headless Chromium и выводит ошибки и предупреждения консоли страницы.

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```
```bash
node tools/shots.js shots 0 square:-1440,1300,25:-1487,1263,0 bridge:-1760,1640,15:-1690,1712,0:60
```

- Вид задаётся как `имя:x,z,h:tx,tz,th[:fov]`. Здесь `x,z` — камера, `tx,tz` — точка, куда она смотрит. Высоты `h` и `th` отсчитываются от земли **в точке взгляда**, `fov` в градусах. Время суток: `0` день, `1` вечер, `2` ночь.
- Координаты города: метры, x — на восток, z — на юг, площадь Единства примерно в (−1487, 1263). Из широты и долготы в углу экрана: `x = (lon − 26.54) · 62438.48`, `z = (55.8825 − lat) · 111292.73`. Курс c (0 — север, 90 — восток) смотрит вдоль `(sin c, −cos c)`.
- WebGL работает на SwiftShader (без видеокарты), поэтому медленно. Город строится 3–5 минут, каждый кадр — до нескольких минут. Запускайте один браузер за раз (два одновременно не укладывались во время) и в фоне.
- Нужен Playwright с Chromium. В облачных сессиях Claude они уже стоят; в другом окружении: `npm i -D playwright` и `npx playwright install chromium`.
- Страница сама даёт отладке `window.__city`: игрок `P`, `camera`, `terrainH(x, z)`, `setTime`, `teleport` и др. (см. конец [src/main.js](../src/main.js)).

## Координаты LKS-92: `tools/lks92.js`

Данные LGIA лежат в латвийской сетке LKS-92 TM (EPSG:3059), высоты — в системе LAS-2000,5 (над уровнем моря). Перевод туда и обратно точен до миллиметра:

```bash
node tools/lks92.js city -1487 1263
```

Есть и подкоманды `ll LAT LON`, `lks E N`. Как модуль: `const { cityToLKS, lksToCity, toLKS, fromLKS } = require('./tools/lks92.js')`. Центр координат города (0, 0) — это E 658875, N 195919.

## Источники

### OpenStreetMap
- **OSM API** — выгрузка всего в небольшом прямоугольнике (до 0,25 квадратного градуса и 50 000 точек):
  ```
  https://api.openstreetmap.org/api/0.6/map?bbox=W,S,E,N
  ```
  Так собраны `parks.js` и `schools.js` и прочитаны теги развязки у моста Единства (`oneway`, `lanes`, `maxheight` → [src/world/street-tags.js](../src/world/street-tags.js)). Из облака работает.
- **Nominatim** (поиск объектов по названию и типу) работает. Нужен свой `User-Agent` и не чаще запроса в секунду.
- **Overpass** (`overpass-api.de`) из облачного окружения не отвечает: туннель рвётся. Вместо него — OSM API по прямоугольникам.

### Mapillary — уличные фото для фасадов
- API v4: `https://graph.mapillary.com`. Фото по лицензии CC BY-SA 4.0. Используем их как образец, а не как текстуры.
- **Ключ у каждого аккаунта свой**, в репозиторий не кладётся. У владельца он сохранён как сетевой секрет облачного окружения для хоста `graph.mapillary.com`: прокси сам подставляет заголовок `Authorization`. Подходят и `OAuth <ключ>`, и `Bearer <ключ>`. Со своим ключом (`MLY|…`) его можно передать заголовком или параметром `access_token`.
- Поиск снимков в прямоугольнике:
  ```
  /images?bbox=W,S,E,N&fields=id,captured_at,compass_angle,computed_geometry,is_pano,thumb_2048_url&limit=2000
  ```
  Прямоугольник держите маленьким, около 0,004° × 0,004°. На больших API отвечает 502 или пусто.
- Покрытие (ноябрь 2026):

  | Место | Снимков | Годы | Панорамы |
  |---|---|---|---|
  | Центр крепости | ~3 000 | 2019–2025, больше всего 2020 и 2024 | нет |
  | Rīgas iela | ~2 100 | 2016, 2019–2025 | 53 |
  | Церковная горка | ~1 500 | 2019–2021 | нет |

### LGIA — Латвийское агентство геопространственной информации
Открытые данные публикуются через [data.gov.lv](https://data.gov.lv) (поставщик в каталоге — «ĢEOLatvija.lv»). Каталог отвечает из облака, поиск:

```
https://data.gov.lv/dati/api/3/action/package_search?q=…
```

- **Модель рельефа, сетка 20 м** (CC0) — уже используется: [terrain.js](../terrain.js), собирается `tools/terrain.js`.
- **Облака точек лазерной съёмки** (набор «Digitālā augstuma modeļa pamatdati», CC0, без регистрации). Съёмка 2013–2019.
  - Тайлы LAS по 1 × 1 км, около 250 МБ каждый. Список всех 65 917 ссылок:
    ```
    https://s3.storage.pub.lvdc.gov.lv/lgia-opendata/las/LGIA_OpenData_las_saites.txt
    ```
    Адрес одного тайла:
    ```
    https://s3.storage.pub.lvdc.gov.lv/lgia-opendata/las/<лист>/<имя>.las
    ```
  - Имя тайла — `<лист>-<RC>-<rc>`. Лист — квадрат 25 × 25 км. `RC` — квадрат 5 × 5 км внутри листа, `rc` — квадрат 1 × 1 км внутри него. R и r — ряд от южного края (1–5), C и c — столбец от западного (1–5). Город (E 652–666 км, N 189–203 км) лежит на листах **2443** (E 650–675, N 175–200 км) и **3421** (E 650–675, N 200–225 км). Центр — `2443-52-14`.
  - Формат: LAS 1.2, точки формата 1 (по 28 байт). Координаты в LKS-92, плотность в центре около 5,8 точки на м².
  - Классы: 2 — земля, 3/4/5 — низкая, средняя и высокая растительность, **6 — здания**. Класс 14 у воды встречается, но его смысл не проверен.
  - Границы тайла читаются без скачивания: заголовок `Range: bytes=0-226`, в нём min/max X, Y, Z со смещения 179.
  - Используется: высоты карнизов и коньков и формы крыш зданий (`tools/lidar.js` → `lidar.js`, раздел README «Высоты и крыши зданий по лидару»). Ещё не используется, но доступно: места и высоты деревьев (классы 3–5), рельеф точнее 20 м (класс 2).
- **Ортофото 25 см** (7-й цикл, 2019–2021, WMS) — CC BY 4.0, бесплатно, но по регистрации на `e-pieteikumi.lgia.gov.lv`. Даёт цвет и материал крыш, дворы. Пока не подключено.
- **Ортофото городов 1997–2002** (CC0) — облик до перестроек.

### Кадастр
Контуры, этажность, год постройки, материал стен и крыши — открытые данные Государственной земельной службы (VZD), уже используются (`tools/cadastre.js`, см. README).

### Фото
- **Wikimedia Commons** — фото со свободной лицензией, по ним сделаны Церковная горка, парки, школы. Из облака API часто отвечает 429 (лимит на общий адрес): нужны паузы и повторы. Агент для чтения веб-страниц может не разрешить имя хоста вовсе.
- **Google Street View** — только как образец: владелец присылает скриншоты (по ним сделан проезд под мостом Единства). Широта, долгота и курс из угла экрана переводятся в вид для `tools/shots.js`, см. выше.

## Механизмы движка, появившиеся недавно

- **Мелкая поправка рельефа** (`PATCH` в [src/world/terrain.js](../src/world/terrain.js)). Это сетка 1 м поверх сетки 20 м в небольшой рамке; её добавляют к высотам и шейдеры, и JS. Для мест, которые сетка 20 м не передаёт. Пример — [src/world/underpass.js](../src/world/underpass.js), разделы README «Daugavas iela под мостом Единства» и «Рельеф».
- **Улицы на дамбах** (`terrainDams`) — ровный гребень дамбы под улицей.
- **Теги OSM по отдельным путям** ([src/world/street-tags.js](../src/world/street-tags.js)): полосы, загородные участки, односторонние съезды в одну полосу.
