СВОЙ СЕРВЕР «ДАУГАВПИЛС 3D» — ЗАПУСК БЕЗ УСТАНОВКИ
===================================================

В этом архиве уже есть всё: Node.js, игровой сервер и сама страница города.
Ничего устанавливать не нужно.

ЗАПУСК
  Windows:  дважды щёлкните «start.cmd».
  Linux:    в терминале  ./start.sh

Запускаль спросит название сервера, порт, режим, ботов и арену
(Enter — оставить значение по умолчанию). Настройки сохраняются
в config.json: при следующем запуске всё уже будет как вы выбрали.

КАК ИГРАТЬ
  Откройте в браузере адрес, который напишет запускаль, например:
    http://localhost:8787          — вы сами
    http://192.168.1.50:8787       — друзья в вашей сети (Wi-Fi/роутер)
  Сервер с вашим названием уже будет в списке на стартовой карточке —
  остаётся ввести ник и нажать «Играть».

  Если Windows спросит «Разрешить доступ к сети?» — нажмите «Разрешить»
  (частные сети), иначе друзья не подключатся.

ИГРА ЧЕРЕЗ ИНТЕРНЕТ
  Чтобы друзья подключались из интернета, пробросьте порт сервера
  (по умолчанию 8787, TCP) в настройках роутера на этот компьютер
  и дайте друзьям адрес http://ВАШ-ВНЕШНИЙ-IP:8787
  (внешний IP показывает, например, 2ip.ru). Страница и сервер живут
  на одном адресе, ничего больше открывать не нужно.

ДАННЫЕ
  Аккаунты игроков:      server/data/accounts.json
  Таблица лидеров:       server/data/leaderboard.json
  Настройки сервера:     config.json
  Сохраняйте эти файлы, если хотите перенести сервер.

ОСТАНОВИТЬ
  Ctrl+C в окне запускаля или просто закройте окно.

ОБНОВИТЬ
  Скачайте свежий архив со страницы
  https://github.com/nikolajevs/DPILS/releases/tag/server-kit
  и перенесите в него свои config.json и папку server/data.
