# Даугавпилс 3D

Город, по которому можно пройтись пешком или пролететь: [daugavpils.html](daugavpils.html), данные города [citydata.js](citydata.js), транспорта [transit.js](transit.js), крепости [fortress.js](fortress.js) и рельефа [terrain.js](terrain.js).

## Источники данных

- **OpenStreetMap** © участники OpenStreetMap, ODbL: улицы, вода, зелень, контуры зданий, названия.
- **Кадастр Латвии** — Государственная земельная служба (VZD), открытые данные [data.gov.lv](https://data.gov.lv/dati/lv/dataset/kadastra-informacijas-sistemas-atvertie-dati), CC BY 4.0: контуры зданий, этажность, год постройки, материал стен и покрытие крыши. По ним выбираются высота дома, стиль фасада (кирпич, силикатный кирпич, панели, дерево) и форма крыши.

- **Расписание транспорта** — официальный GTFS «Daugavpils satiksme» ([satiksme.daugavpils.lv/saraksti/GTFS.zip](https://satiksme.daugavpils.lv/saraksti/GTFS.zip)): трамвайные и автобусные маршруты, остановки и время каждого рейса. Трамваи и автобусы в городе едут по этому расписанию по времени Риги; часы можно перематывать и ускорять.

Фасады и крыши нарисованы процедурно, это не фотографии.

## Дом Единства и гостиница «Латгола»

Два здания на площади Единства построены вручную, а не общим генератором фасадов (`buildLandmarks` в [daugavpils.html](daugavpils.html)). Размеры сняты с фотографий и сверены с контуром кадастра: ширина портика 29,4 м, карниз ≈18 м, шесть колонн ≈12 м.

- **Дом Единства** (Vienības nams, арх. Вернер Витандс, 1936–1937): портик с шестью коринфскими колоннами и лоджией, пилоны с рустом и надписью «VIENĪBAS NAMS», театральные витрины, сценическая коробка с флагом, крылья с магазинами на Rīgas iela и Ģimnāzijas iela, вход в концертный зал, терраса юго-западного крыла, двор.
- **Park Hotel Latgola** (бывшая гостиница «Latvija», 1975–1985, реконструкция 2000-х): волнообразная кровля над остеклённым верхним этажом, рамка двухсветного окна, стеклянный объём лестниц, часы на крыше (показывают время города), вывески HOTEL и PLAZA; рядом жёлтый торговый центр Latgola.
- **Клумбы**: ковровая клумба перед портиком (шалфей, цинерария, бархатцы, бегонии) с двумя пятишаровыми канделябрами и скамейками, клумба у входа в концертный зал.

Источники фото: Wikimedia Commons (категории *Latgola Hotel*, *Vienības laukums (Daugavpils)*, файл *Vienības nams.jpg* в латышской Википедии), [visitdaugavpils.lv](https://www.visitdaugavpils.lv/en/?p=3245) (в том числе снимки 1937 года), [celotajs.lv](https://www.celotajs.lv/en/e/vienibasnams), [militaryheritagetourism.info](https://militaryheritagetourism.info/lt/military/sites/view/891), [neighborhood.lv](https://neighborhood.lv/en/real-estate/daugavpils-architectural-guide/); проект реставрации фасада Дома Единства — Daugavpils pilsētas dome, 2010.

## Даугавпилсский университет

Три корпуса университета тоже построены вручную (`lmDUMain`, `lmDUParades`, `lmDULab` в [daugavpils.html](daugavpils.html)). Контуры взяты из кадастра, детали сняты с фотографий.

- **Старый корпус**, Vienības iela 13 (арх. Алексей Богаченков, 1952–1956; строился для обкома, достроен для пединститута). Фасад на сквер с фонтаном 76,7 м: глухие угловые пилоны по 8,4 м, одиннадцать осей по 5,45 м между десятью пилястрами высотой в четыре этажа, с капителями на уровне верхних окон. Окна парные, этажи через 3,95 м, в трёх средних осях дубовые двери в каменных обрамлениях. Во фризе высотой 3 м бронзовые буквы DAUGAVPILS UNIVERSITĀTE, карниз на модульонах на отметке 21,5 м, в центре аттика картуш с флагом. Охристая штукатурка рустована под квадры, цоколь гранитный. Сзади три крыла (план «Ш»). Перед фасадом гранитная лестница, ряд туй и бюст Райниса (1967).
- **Новый корпус**, Parādes iela 1 (1980-е, у Дубровинского парка). План восстановлен по кадастру и схемам этажей с информационного стенда университета. Пятиэтажные коридорные крылья (одно повёрнуто на 45°) облицованы бежевой керамической плиткой, крыша низкая, шиферная. Лестничные башни из красного кирпича. Внутри угла двухэтажные кирпичные корпуса: вестибюль, библиотека на колоннаде, концертный зал, спортзал. У них ленточные окна в белых рамах с белыми подоконными поясами и кирпичная решётка. Портик входа с двухстрочной стальной надписью DAUGAVPILS UNIVERSITĀTE. На внешнем углу одноэтажный блок амфитеатральных аудиторий, на крыше спутниковая антенна.
- **Лабораторный корпус**, Parādes iela 1A (SIA «Nams», 2014; площадь застройки 3568 м², два этажа). Белые трёхслойные железобетонные панели с высоким ленточным окном, сверху витраж Schüco FW50+ с тёмными горизонтальными ламелями на южных и западных фасадах. Белый входной объём с консолью над дверями, стеклянный атриум, техника на крыше, застеклённый переход к новому корпусу.

Источники фото и сведений: Wikimedia Commons (категория *Daugavpils University*: Igors Jefimovs 2011, Dāvis Kļaviņš 2010, снимки panoramio), статьи о Даугавпилсском университете в латышской и русской Википедии, [du.lv](https://du.lv/en/about-us/environmental-accessibility/macibu-korpuss-parades-iela-1/) (схемы этажей корпуса на Parādes iela 1), [archidea.lv](https://archidea.lv/lv/portfolio/portfolio/archidea/architecture/71/) («Gada labākā būve Latvijā 2014»: описание и фото лабораторного корпуса).

## Бывший кинотеатр «Ренесанс»

Кинотеатр «Oktobris» (1978), позже «Renesanse», Vienības iela 30; с 2022 года в нём Daugavpils Inovāciju centrs (`lmRenesanse` в [daugavpils.html](daugavpils.html)). В OpenStreetMap здание нарисовано частями-отношениями (building:part), которые сборка данных не скачивала. Поэтому в `citydata.js` его не было: от общего контура остался только центр (место «Daugavpils inovāciju centrs»). Ещё уцелела единственная часть-линия: полоса 27 × 2,5 м перед зданием, то есть козырёк над фойе. В городе она стояла отдельным «домиком», теперь убрана. План привязан к этому козырьку и поставлен перпендикулярно Vienības iela. Модель сама добавляет свой контур для столкновений, карты и посадки деревьев. Точный план по фото не восстановить, поэтому глубина корпусов приблизительная.

Здание целиком из жёлтого кирпича:

- большой зал на западе со скруглённым углом и вентиляционной решёткой;
- фойе между залами: лента верхних окон над толстым козырьком со скруглённым краем, под ним остекление в чёрных рамах с матовым орнаментом и светодиодная вывеска Инновационного центра;
- более высокий восточный объём со скруглённым фасадом;
- малый зал и служебный корпус позади;
- гранитная терраса, лестница и пандус со стальными перилами.

Запрос [tools/queries/q_rel.txt](tools/queries/q_rel.txt) теперь скачивает и отношения building:part, а `tools/process.js` превращает их в здания. Данные появятся после следующей пересборки `citydata.js`. Участок кинотеатра зарезервирован за ручной моделью.

Источники: Wikimedia Commons (категория *Cinemas in Daugavpils*: «Daugavpils oktobris cinema», «Кинотеатр Ренесанс — panoramio»), [lsm.lv](https://www.lsm.lv/raksts/dzive--stils/tehnologijas-un-zinatne/daugavpili-atvertais-inovaciju-centrs-vilina-gan-bernus-gan-pieaugusos.a486412/) (фото 2022 года), [visitdaugavpils.lv](https://www.visitdaugavpils.lv/en/turisma-objekts/daugavpils-innovation-centre/).

## Динабургская крепость: валы, рвы и ворота

Земляные укрепления строятся из OpenStreetMap ([fortress.js](fortress.js), собирается `tools/fortress.js`). В OSM подпорные стены и насыпи рисуются так, что низкая сторона справа от линии: замкнутая подпорная стена — это контур поднятого укрепления (бастион, люнет, контргард), главный эскарп — полоса между двумя линиями. По ним строится рельеф с шагом 2 м:

- **рвы** — дно на 4 м ниже города вдоль канав, нарисованных в OSM по дну рвов, и по полигонам рвов; в мокрых рвах — заболоченное дно и вода в канавах;
- **эскарп** — облицовка из бутового камня (гранитные валуны) высотой 1,6 м над уровнем города, за ней берма под дерновым покрытием, затем откос до гребня бруствера 5,2 м и терреплейн 4,2 м;
- **дороги** держат свой уровень, к валам и рвам от них идут земляные откосы; дорожки ложатся на рельеф;
- по валам и во рвах можно ходить: высота шага берётся из того же рельефа, облицовка рвов не пускает спрыгнуть вниз.

Ворота смоделированы по фотографиям (Wikimedia Commons, visitdaugavpils.lv, militaryheritagetourism.info):

- **Николаевские** — внешний фасад из красного кирпича со стрельчатой аркой в гранитном обрамлении, боковыми стрельчатыми нишами с решётками, бойницами, алебардами, фризом с надписью «НИКОЛАЕВСКІЯ», аркатурой и аттиком с двуглавым орлом; внутренний фасад — розовая штукатурка с белыми деталями, тюдоровская арка с открытыми дубовыми створками, боковые арочные ниши с окнами; деревянный мост на козлах через ров с кирпичными столбами и орлами у контрэскарпа.
- **Михайловские** — гранитные порталы в египетском стиле с карнизом-выкружкой, крылатым диском и ликторскими секирами; со стороны крепости — изогнутые подпорные стены из песчаника, по верху которых спускается вал.
- **Александровские** — кирпичные порталы с полуциркульной аркой в гранитном обрамлении и фризом-меандром.
- **Потерны** — малые кирпичные проходы сквозь вал.

Константиновские ворота пока не смоделированы.

Здания крепости по фотографиям (категории Wikimedia Commons *Artillery arsenal (Daugavpils fortress)* и *Engineering Arsenal (Daugavpils Fortress)*) и контурам OSM:

- **Артиллерийский арсенал** (с 2013 года — Центр Марка Ротко): П-образное здание 119 × 42 м, открытое во двор. Первый этаж рустован, группы из трёх высоких окон между белыми пилястрами, фриз с сухариками; над каждой группой — люнет в широком белом архивольте с замковым камнем; белый карниз, вальмовая кровля из фальцевой стали с круглыми вентиляционными шапками. На торцах крыльев — одноэтажные пристройки, к их крышам поднимаются пандусы с арочным проходом; у главного входа — навес и гранитные цветочницы, во дворе — флаги.
- **Инженерный арсенал** (реставрирован в 2023 году): два крыла клином, сходящиеся к торцевому корпусу на улице Александра. Фасады на улицы жёлтые в том же ордере, во двор — красный кирпич; дубовая дверь с табличкой «ИНЖЕНЕРНЫЙ АРСЕНАЛЪ», ряды кирпичных труб на кровле.
- **Фонтан в саду крепости**: четыре чугунных ствола на квадратных казёнах, сходящиеся вверху, на гранитном постаменте с надписью ДИНАБУРГЪ, в круглой чаше; ограда из столбиков с цепями. Исторические орудия, отмеченные в OSM, стоят на лафетах, мортира — на станке.
- **Комендантский дом** (улица Коменданта, 7): двухэтажный корпус 107 м с трёхэтажной центральной частью, выступающей вперёд; бледно-охристая штукатурка, первый этаж рустован, над окнами белые замковые камни, окна второго этажа в белых наличниках с карнизиками; в центре аркада из пяти арок с дверью в средней, по сторонам лестницы — пушки; белые трубы на коньке. Сейчас в здании Управление Латгальского региона Государственной полиции (в OSM — amenity=police, Komandanta iela 7): металлические буквы VALSTS POLICIJA над аркадой, табличка у двери, флаги на газоне, ограда вдоль фасада с проходом к двери и служебная стоянка за домом (110 × 34 м по OSM) со служебными и личными машинами.
- Оштукатуренные казармы и склады крепости красятся в охристые, жёлтые и лососевые тона, как на фотографиях.

Пересобрать `fortress.js`:
```bash
curl -o map.osm "https://api.openstreetmap.org/api/0.6/map?bbox=26.4807,55.8789,26.5096,55.8933"
```
```bash
node tools/fortress.js map.osm fortress.js
```

## Rīgas iela

Пешеходная Rīgas iela (около 850 м от Vienības laukums до вокзала) прорабатывается по кварталам (`lmRigas`, `lmStreetHouse` в [daugavpils.html](daugavpils.html)).

- **Мостовая** по всей пешеходной части: красная бетонная брусчатка, по оси гранитная полоса, вдоль домов гранитные плиты (по фото 2010-х).
- **Генератор исторических домов.** Дом описывается одной строкой в `RIG_HOUSES`: точка внутри кадастрового контура, этажи и высоты, цвет штукатурки или красный кирпич, число осей, первый этаж (витрины, арочные окна, двери, проезд с воротами), тип окон (прямые, лучковые, полуциркульные). Дальше идут декор и крыша:
  - наличники, сандрики и фронтончики над окнами, филёнки под окнами;
  - руст, междуэтажный пояс, угловые квадры, лопатки;
  - карниз на кронштейнах или с сухариками, аттик с фронтоном, балконы с коваными решётками;
  - металлическая крыша со скатом к улице и трубами.

  Фасад по Rīgas iela собирается полностью. Стены на другие улицы получают тот же фасад, но с окнами вместо витрин. Дворовые стены получают простые окна, брандмауэры остаются глухими. Столкновения дают кадастровые контуры.
- **Готово:** первые два квартала от площади Единства по южной стороне (9 домов). Этажность и контуры взяты из кадастра. Отдельных фото этих домов в открытых источниках нет, поэтому фасады собраны в типичных для Rīgas iela формах по общим снимкам улицы (Wikimedia Commons, категория *Rīgas iela (Daugavpils)*). Уточняются по фото конкретных домов.

## Гастробар «Vēsma», Rīgas iela 49

Одноэтажный павильон на северной стороне пешеходной улицы, сделан отдельно по фото и месту из [visitdaugavpils.lv](https://www.visitdaugavpils.lv/en/turisma-objekts/vesma-cafe/) (`lmVesma`). Кадастровый контур 43 × 12 м включает крытую летнюю террасу. Остеклённый фасад стоит на 3,8 м глубже, на одной линии с нишей входа в западном крыле.

- Поверху идёт фриз из тёмно-зелёной доски: надпись «VēsmA» белыми курсивными буквами в бирюзовой и тёмно-зелёной обводке, бирюзовая и белая полосы, «BĀRS ⓥ BISTRO», пёрышко-логотип. Ночью надписи светятся.
- На крыше терраса со стальными перилами и фонарями-шарами.
- Летняя терраса: тёмно-зелёные стальные стойки, тонкая кровля с кремовым тентом снизу, тонированное стеклянное ограждение с баннерами Aldaris, деревянный настил, подвесные кашпо с цветами, столики и плетёные кресла.
- Вход: стеклянные двери, две каменные ступени, белая колонна на углу, можжевельники у западного крыла.

- красные заградительные огни, ночью светятся.

## Железнодорожный вокзал

Вокзал Даугавпилса (Stacijas iela 44, 1951), модель `lmStation` в [daugavpils.html](daugavpils.html). План — контур OpenStreetMap (way 115889829), облик — фото из категории Wikimedia Commons *Daugavpils Railway Station*.

Здания в `citydata.js` не было. В OSM внутри контура нарисован навес над входом как часть здания (building:part=roof), и сборка данных подставила эту часть вместо всего вокзала, так что остался навес 11 × 3 м. Теперь `tools/process.js` отдаёт контур частям, только если они покрывают больше половины его площади, а части-навесы рисует как навесы на столбах. Подействует при следующей пересборке; до неё навес отброшен вручную, а модель сама регистрирует свой контур.

- Охристая штукатурка на красно-коричневом цоколе.
- Посередине объём через всё здание под двускатной крышей с фронтонами с обеих сторон.
- К площади: портик с двумя квадратными столбами, к нему 17 ступеней с тремя поручнями и боковой площадкой. Над портиком глубокая полуциркульная ниша с архивольтом и замковым камнем, она врезается во фронтон; в нише крылатое колесо, эмблема железной дороги. В боковых пилонах ряды узких окон.
- К перронам: заглублённая ниша с остеклёнными дверями и большим окном, бронзовые буквы DAUGAVPILS, год «1951» в люнете фронтона.
- По сторонам залы ожидания: по четыре высоких окна между пилястрами на обоих фасадах, слуховые окна на крышах.
- По краям двухэтажные корпуса под вальмовыми крышами с трубами, окна в четыре оси, ромбики между окнами второго этажа, решётки подвальных окон в цоколе.
- Низкий асфальтовый перрон по контуру OSM с белой кромкой.

## Спидвей-стадион «Локомотив»

Стадион Lokomotīve на Jelgavas iela 54, домашний трек спидвей-клуба «Локомотив»: открыт в 1963 году (405 м), с 1996 года длина круга 373 м. Модель `lmSpeedway` в [daugavpils.html](daugavpils.html).

Откуда взята геометрия:

- **OpenStreetMap**: внешняя кромка трека (площадь raceway, relation 20362487), граница травяного поля (way 803378638), точка старта и финиша, контуры трибун (ways 130274825 и 130274821), навес боксов (way 803378635) и двенадцать мачт освещения.
- **Схема стадиона клуба** ([lokomotive.lv](https://www.lokomotive.lv/stadiums/lokomotiv), 2026): главная трибуна A вдоль Jelgavas iela с секторами A–F и VIP, трибуна B напротив, боксы и паддок со стороны Arodu iela, линия старта перед сектором VIP, ворота на трек в вершинах виражей. Там же ширина трека: 11,2 м на прямых, 16,3 м в виражах. По OSM выходит столько же.
- **Облик** — фотографии из галереи клуба.

Что построено:

- **Трек.** Кромки сглажены, внешняя ведётся по нормалям от внутренней, поэтому ограждение и надувные борта идут параллельно полотну. Гранитное покрытие темнее на траектории у бровки и светлее у забора, где лежит отброшенная крошка. У бровки белый бортик. Поле выкошено полосами поперёк трека.
- **Старт.** Меловая линия старта и финиша и четыре стартовые позиции. Три ленты стартовой машины натянуты между столбиками на поле и у забора. На заборе и на поле клетчатые щиты.
- **Ограждение.** Тёмные доски на белых столбах с поручнем. Вдоль прямых рекламные щиты, в виражах оранжевые надувные борта секциями по 5 м. В вершинах виражей открыты ворота: из паддока и для скорой.
- **Трибуны A и B.** Пятнадцать рядов по 0,8 м с подъёмом 0,42 м над стенкой высотой 1,3 м с проходом. Около 6200 синих сидений (инстансы), на трибуне A каждый четвёртый ряд жёлтый. Бежевые (на B — белые) лестницы с половинными ступенями между секторами, чёрные поручни. Ограждение по фронту, портал тоннеля к треку под первыми рядами. Задняя стена — каркас с пилястрами и дверями, на A главный вход с Jelgavas iela за сектором VIP.
- **Навес над центром трибуны A** (секторы C, VIP, D): десять пологих сводов из светопрозрачного листа на консольных фермах, колонны в задней стене. Под навесом жёлтая кабина комментаторов и пять прожекторов над домашней прямой.
- **Трибуна B.** Жёлтые рифлёные щиты вдоль верхнего прохода, перила по задней стене, за ней флагштоки с флагами стран гонщиков.
- **Мачты.** Серые опоры с двумя светильниками, повёрнутыми к треку. Вечером и ночью светятся и дают пятна света на дорожке.
- **Боксы.** Десять боксов под синими двускатными крышами, открытые к паддоку, в каждом верстак. Асфальт в паддоке, перед трибунами и на стоянке у трибуны B, плитка у главного входа.
- **Рельеф и проходы.** Площадка стадиона выровнена: земля там падает на 1,5 м к Jelgavas iela. По трибунам можно ходить: на них поднимаются с переднего прохода и идут по рядам вверх. Забор пускает на трек только через ворота.

## Типовые советские 5–9-этажки

Около 340 жилых домов — типовые проекты 1960–80-х. Они распознаются по контуру и этажности и рисуются секциями настоящего ритма, а не общими ячейками окон (`serBuild`, `seriesAtlas`, `seriesMaterial` в [daugavpils.html](daugavpils.html)). Фасады показаны такими, какими были построены, до утепления.

Длину секции дали сами контуры. 5-этажки глубиной 10,5–12,5 м встречаются длиной 48, 64–65, 80, 96 и 128 м, то есть 3, 4, 5, 6 и 8 секций по 16,1 м. Облик снят с фото из категории Wikimedia Commons *Apartment buildings in Daugavpils*: Stadiona iela 4, Cietokšņa iela 55A, Andreja Pumpura iela 55, Krišjāņa Valdemāra iela 5, Nometņu iela 25.

- **k5** (282 дома): 5-этажный дом из силикатного кирпича.
  - На одной стороне подъезды с козырьками, дверями и ступенями, над ними лестничные окна между этажами.
  - На другой стороне пары колонн балконов (часть застеклена) или одни окна.
  - На торце колонка окон, водостоки на стыках секций.
  - Низкая двускатная или плоская крыша с парапетом, по признаку из кадастра.
- **p5** (48): 5-этажный панельный дом глубиной 13–17 м: швы панелей, лоджии во всю длину с перегородками и выборочным остеклением.
- **n9** (17): 9-этажный панельный дом. Его длина кратна секции 25,9 м: 26, 52, 78 и 104 м. На подъездной стороне лестничные окна, на другой — по две колонны лоджий на секцию с ребристыми экранами, часто красно-коричневыми. На крыше машинные отделения лифтов.
- **t9** (9): 9-этажный кирпичный дом из секций около 19 м: колонны балконов, на части домов красные экраны.

Атлас хранит одну секцию на один этаж: первый, типовой и верхний этаж каждого фасада и торец. Шейдер повторяет ячейки по секциям и этажам, ночью зажигает окна вразнобой. Цвет кирпича или панелей берётся из палитры серии. Какая сторона подъездная, а какая балконная, выбирается случайно: в данных этого нет.

## Деревья и вода

Деревья не ставятся в воду: ни в водные полигоны (реки, озёра, пруды в опущенном русле) ближе 1,2 м к урезу, ни на ленты ручьёв. Для скорости используется растровая маска воды с ячейкой 4 м; точная проверка делается только у берегов.

## Рельеф

Город не плоский. Высоты земли — цифровая модель рельефа Латвийского агентства геопространственной информации (LGIA): голая земля по аэролазерному сканированию 2013–2019 годов, сетка 20 м, система высот LAS-2000,5, открытые данные ([data.gov.lv](https://data.gov.lv/dati/lv/dataset/digitlais-reljefa-modelis-ar-tkla-soli-20m)). В отличие от спутниковых моделей в ней нет леса и крыш, и русло Даугавы, насыпи и выемки дорог, овраги лежат на своих местах. Данные лежат в [terrain.js](terrain.js). Перепад по городу около 60 м: вода Даугавы — 88–89 м, центр — 93 м, Церковная горка — 108 м, Химия — 117 м, возвышенность к югу от Гривы — до 150 м.

- Каждая вершина поднимается на высоту земли под ней прямо в шейдерах three.js (общие куски `project_vertex` и `worldpos_vertex`, в том числе в материалах теней), так что за рельефом следуют земля, улицы, деревья, фонари, трамваи и автобусы.
- **Вода** лежит на своём уровне: в модели это самая низкая земля вокруг, поэтому поверхность реки или озера в каждой точке — минимум высот в радиусе 50 м; берега спускаются к ней откосом.
- **Железная дорога** идёт ровным профилем: на сетке 20 м узлы попадают то на полотно, то на откос насыпи или бровку выемки, и высоты вдоль пути скачут на метры. Для каждого пути строится профиль (медиана высот по ±70 м, среднее по ±150 м, уклон не круче 1,2 %), сетка в 10 м от пути получает его, а к 30 м плавно возвращается к рельефу — получаются насыпь или выемка. Мосты не трогаются.
- Обычные дома стоят ровно, на самой низкой точке своего контура; на склоне их цоколь уходит в землю.
- Мосты держат прямой настил от высоты одного берега до другого; Vienības tilts сохраняет свой изгиб над серединой, опоры доходят до воды.
- Земля разбита на треугольники там, где рельеф изгибается, а невидимая сетка глубины на 0,6 м ниже земли даёт холмам заслонять то, что за ними, и отбрасывать тень.
- Крепость стоит на выровненной площадке с высотой окружающей местности.
- Пешеход поднимается в горку и спускается в низины; в полёте нельзя опуститься ниже 2 м над землёй.

Пересобрать `terrain.js`: скачать и распаковать `DTM_Latvija_20m.7z` (≈400 МБ, внутри текстовый файл 4,7 ГБ, строки «восток север высота» в LKS-92 TM), затем
```bash
node tools/terrain.js citydata.js terrain.js --lgia DTM_Latvija_20m.txt
```
Запасной источник — AWS Terrain Tiles (EU-DEM, сглаженный; тайлы кешируются в папке):
```bash
node tools/terrain.js citydata.js terrain.js --tiles terrain-tiles
```

## Как пересобрать `citydata.js`

1. Скачать OpenStreetMap через Overpass API запросами из [tools/queries](tools/queries) в файлы `build.json`, `rest.json`, `rel.json` (одна папка).
2. Скачать с data.gov.lv кадастровые SHP для Даугавпилса (`0002000_kk_shp.zip`) и Аугшдаугавского края (`0022000_kk_shp.zip`), распаковать; из `building.zip` взять XML этих же территорий.
3. Собрать здания кадастра:
   ```bash
   node tools/cadastre.js cadastre.json kk_shp kk_shp2 -- Building/0002000_*/*.xml Building/0022000_*/*.xml
   ```
4. Собрать город:
   ```bash
   node tools/process.js osm cadastre.json citydata.js
   ```

## Как обновить расписание `transit.js`

Скачать и распаковать свежий GTFS «Daugavpils satiksme», затем:
```bash
node tools/transit.js gtfs citydata.js transit.js
```
